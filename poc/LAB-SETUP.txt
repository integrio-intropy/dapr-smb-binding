Lab used for the PoC (Ubuntu 24.04, single host)

Server: Samba 4.19.5 AD DC, realm LAB.TEST, host dc1.lab.test
  smb.conf [global] additions:
    ntlm auth = disabled            # NTLM refused (server returns STATUS_NTLM_BLOCKED)
    server min protocol = SMB3
    server smb encrypt = required
  share: [exchange] path=/srv/exchange (in/, out/, processing/)
  account: svc-intropy, keytab exported with `samba-tool domain exportkeytab`

Client: Python 3.12, smbprotocol 1.17.0, pyspnego 0.12.4, gssapi 1.12.0, krb5 0.10.0
  pip install 'smbprotocol[kerberos]'   (needs gcc, python3-dev, libkrb5-dev at build time)
  /etc/krb5.conf: explicit kdc, dns_lookup_kdc=false, udp_preference_limit=1

Run:
  KRB5CCNAME=MEMORY:poc python smb_poc.py ntlm-negative
  KRB5CCNAME=MEMORY:poc python smb_poc.py password
  KRB5CCNAME=MEMORY:poc KRB5_CLIENT_KTNAME=/path/svc.keytab python smb_poc.py keytab
  Renewal: KRB5_CONFIG=krb5 with ticket_lifetime=180s, KRB5_CLIENT_KTNAME=..., python renew_test.py
